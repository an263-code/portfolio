Radius & Padding

Our spatial system uses consistent rules for corner radii and internal padding to maintain a clean, approachable UI.

Radius rules

Small (4px)

Used for small components like checkboxes, tags, or tooltips. It provides a subtle hint of softness without losing a "precise" feel.

Medium (16px)

The "sweet spot" for buttons, input fields, and standard cards. This is usually the signature "look" of the brand.

Large (24px)

Used for avatars, chips, or prominent "Call to Action" buttons.

Padding rules

Tight (4px - 8px)

Internal element spacing, like the gap between an icon and text, or tightly grouped list items.

Standard (16px - 24px)

Component padding for buttons, input fields, and standard lists. Pairs perfectly with Medium radii.

Spacious (32px - 48px)

Container padding used for cards, modals, and major section breaks to let the UI breathe.

Visual Harmony Principle

To maintain visual harmony when one rounded element is inside another, the outer radius must be larger than the inner radius.

Outer Card: 24px Radius / 24px Padding

Before / After

The "Comparison" Component: Two frames showing the original and the redesign, with an optional "what changed" note attached to the Before frame so the rationale travels with the original. Pick the layout that fits the content — side-by-side when frames stay legible at half-width, stacked when each image needs the full width to read.

Side-by-side (horizontal)

Stacked (vertical)

Use .compare--horizontal for side-by-side or .compare--vertical for stacked. Horizontal collapses to stacked at ≤720px automatically. The .compare-note inside the Before frame is optional — drop it for a clean two-frame comparison.

Carousel

The "Iteration Showcase" Component: Walks the reader through multiple versions of the same idea — early sketches, A/B explorations, refined final — with a comment on each frame explaining what changed and why. One slide visible at a time keeps focus; arrows, dots, and ←/→ keys move between iterations. Click any image to open a full-size preview in a modal (close with ✕, the backdrop, or Escape).

Step label (.carousel-step): Montserrat / --action-sage / 14px / UPPERCASE / letter-spacing 0.1em / weight 700

  1. Iteration 1

    Started with a single-column list. Quick to build, but it buried the comparison the user actually needed.

  2. Iteration 2

    Tried a side-by-side layout. Comparison improved, but the right column ran out of room on smaller screens.

  3. Iteration 3

    Grouped tiles by source. Cleaner hierarchy, but users couldn't tell which tiles were active.

  4. Iteration 4 · Final

    Kept the grouping, added a colored status pill per tile. Comparison stays scannable; active state is unambiguous.

A gold variant of the Insight Callout, without the quote icon. Use it to surface a key metric or adoption summary — the gold fill ties it to the year-end usage / data moments in case studies. Add the data-callout--media modifier with a data-callout-media block to lead with an image (e.g. a Pendo chart) — it is click-to-zoom, same as image cards.
